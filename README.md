## Quelques projets

**[Planche de Galton](https://github.com/AmielPouzat/Site-Planche-de-Galton-pour-githuub)**  
Une simulation de la loi binomiale, avec une animation des billes, une comparaison aux effectifs théoriques et des exports. On peut faire varier les paramètres pour voir ce qui change. L'interface existe en français et en anglais.

Avec **[l'outil d'interpolation](https://pouzat.fr/interpolation)**, on part de couples X/Y pour construire un polynôme de Lagrange. Le calcul donne les coefficients rationnels exacts, ainsi qu'une courbe et les résidus.

Le **[générateur déterministe](https://pouzat.fr/generateur)** reprend un ancien script R dans une interface web, avec la possibilité d'exporter les données en CSV.
